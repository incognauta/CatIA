Aplicación de Chat con Documentos usando IA

El objetivo es desarrollar una aplicación web que permita a los usuarios subir archivos y conversar con su contenido usando inteligencia artificial. La app debe cumplir con lo siguiente:

1. Carga y procesamiento de archivos

La aplicación debe recibir cualquier tipo de archivo (PDF, imágenes, Word, etc.).

Si el archivo no es texto, debe usar OCR para extraer la información.

Todo el contenido del archivo debe convertirse automáticamente a formato Markdown.

2. Generación de chat con IA

Una vez procesado el archivo, el sistema debe crear automáticamente un chat con IA.

El usuario podrá hacer preguntas y conversar sobre el contenido del documento.

La IA debe responder usando solo la información del archivo cargado.

3. Registro y autenticación de usuarios

La aplicación debe permitir registro e inicio de sesión de usuarios.

Cada usuario solo puede acceder a sus propios archivos y conversaciones.

4. Historial y almacenamiento

El sistema debe guardar el historial de conversaciones.

Cada conversación debe quedar asociada al archivo correspondiente.

Los usuarios deben poder volver a chats anteriores.

5. Pasarela de pagos

La aplicación debe incluir una pasarela de pagos.

El acceso al chat con IA o a ciertas funciones debe estar limitado según el plan de pago.

El sistema debe controlar el estado de la suscripción o créditos del usuario.
